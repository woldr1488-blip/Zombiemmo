🧟 Zombiemmo (Piu piu.io)

Zombiemmo — это кооперативный top-down шутер про выживание против орд зомби. Игра написана на Python + Pygame, поддерживает игру по локальной сети (до 14 игроков) и одиночный режим с автосохранением.

Текущая версия: 1.0 · Обновление: «бездонная дыра» · Патч: v61

✨ Возможности

· 🌊 Волны зомби — 10 / 50 / 100 волн в зависимости от этапа сюжета, плюс бесконечный режим.
· 🧟 7 типов зомби: обычный, бегун, танк, разъярённый, плевун, заражённый, камикадзе.
· 👹 Боссы: обычный (каждые 10 волн), босс 50-й волны с рывками, финальный босс (100-я волна, 1 000 000 HP) с самонаводящимися пулями.
· 🏰 Строительство: баррикады, турели (обычная, огненная, электрическая, ремонтная), двери.
· 🔫 21 вид оружия — от пистолета до «Последней призмы» и «Истинной звёздной пушки».
· 🌐 Мультиплеер по локальной сети (TCP + UDP-обнаружение серверов, до 14 игроков).
· 💾 Соло-режим с автосохранением каждую секунду.
· 🎁 Сундуки 5 редкостей (от редкого до легендарного).
· 🏆 Достижения и разблокировки — сюжет, режимы, оружие, пассивки.
· 🔌 Система модов (addon/) с изолированной песочницей (белый список атрибутов, запрет exec/eval/compile, open() только на чтение внутри папки мода, проверка SHA-256).
· 🎮 Два режима управления: ПК (WASD + мышь) и сенсорный (два джойстика).

💻 Установка

Требования

· Python 3.9+
· Pygame 2.x
· NumPy
· ОС: Windows / Linux / macOS

Шаги

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/woldr1488-blip/Zombiemmo.git
cd Zombiemmo

# 2. (Рекомендуется) создайте виртуальное окружение
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows

# 3. Установите зависимости
pip install pygame numpy
```

🎯 Режимы игры

Режим Описание Как открыть
Обычный Классическое выживание по волнам Доступен сразу
Босс-раш Только боссы Пройти этап 50 волн
ПвП Игроки могут ранить друг друга Пройти этап 50 волн
Защита кристалла Защищайте кристалл от зомби Достижение «Боб строитель»
Бесконечный (сложность) Волны без конца Убить 5 боссов

Сложности

· Лёгкий — HP ×0.7, урон ×0.7.
· Обычный — базовые значения.
· Сложный — HP ×1.5, урон ×1.4, больше врагов (открывается после 50 волн).
· Бесконечный — без лимита волн.

Этапы сюжета

1. 10 волн — стартовый этап.
2. 50 волн — открывает Босс-раш, ПвП, Сложный режим.
3. 100 волн — открывает «Запретное знание».

🔌 Моды

Игра поддерживает пользовательские моды в папке addon/. Каждый мод — это отдельная папка с manifest.json и скриптом main.py.

Структура мода

```
addon/
└── my_mod/
    ├── manifest.json
    └── main.py
```

manifest.json:

```json
{
  "name": "My Mod",
  "description": "Мой мод",
  "script": "main.py"
}
```

main.py может определять хуки: on_start, on_tick, on_draw, on_event, on_kill, on_boss_killed, on_wave_start, on_wave_end, on_player_join, modify_damage, modify_speed, on_player_death, on_player_respawn, on_zombie_spawn, on_victory, on_game_over, on_crate_opened, on_item_used, on_weapon_bought, on_build_bought, on_build_destroyed, on_bullet_hit, on_laser_hit, on_melee_hit, modify_coin_reward, modify_xp_reward, filter_zombie_spawn, filter_weapon_purchase, filter_build_place.

Безопасность

Моды работают в песочнице:

· ❌ Запрещены exec, eval, compile, globals, locals, vars, type, object, super, input, exit, quit.
· ❌ Запрещён импорт os, sys, subprocess, socket, ctypes и т.п.
· ✅ Разрешены только math, random, pygame (через прокси с белым списком атрибутов).
· ✅ open() работает только в режиме чтения и только внутри папки мода.
· ✅ При загрузке с сервера проверяется SHA-256 файла.

Моды включаются в меню Настройки сервера → МОДЫ.

🛠️ Читы и консольные команды

⚠️ Включение читов отключает сохранение статистики в этой сессии!

Читы включаются галочкой в меню создания сервера. Команды вводятся в чат (или в консоль хоста) и начинаются со слеша:

Команда Описание
/xp <цвет\|me\|all> <add\|set\|del> <N> Изменить опыт
/coins <цвет\|me\|all> <add\|set\|del> <N> Изменить монеты
/hp <цвет\|me\|all> <add\|set\|del> <N> Изменить HP
/weapon <цвет\|me\|all> <add\|del> <id> Выдать/забрать оружие
/give <цвет\|me\|all> <item> <N> Выдать расходник
/wave skip Пропустить волну
/wave set <N> Установить номер волны
/wanish <цвет\|me\|all> Режим невидимости

Секретные коды

Их можно вводить в чат как обычный текст:

· ALLDUST31 — сделать себя админом сессии.
· FCKGRAYFRICK — восстановить HP.
· YOUCANT — +50 000 XP и +100 000 монет (один раз за сессию).

📁 Структура проекта

```
Zombiemmo/
├── game.py                 # Вся игра в одном файле
├── zombie_settings.json    # Настройки (создаётся автоматически)
├── gamestate.dat           # Трофеи и достижения (XOR + checksum)
├── solo_save.dat           # Автосохранение соло-игры
├── addon/                  # Папка для модов
│   └── <mod_id>/
│       ├── manifest.json
│       └── main.py
└── music/                  # Звуки и музыка (опционально)
    ├── menu_music.wav
    ├── fon.wav
    ├── shoot.ogg
    ├── swo.ogg
    ├── apple.ogg
    └── zombie.ogg
```

Все сохранения обфусцированы (XOR + контрольная сумма), но не являются криптографически защищёнными — не используйте их для передачи секретов.

⚠️ Известные ограничения

· Один файл: game.py содержит ~6000 строк — вся логика сервера, клиента и рендера в одном месте.
· Нет шифрования трафика: мультиплеер рассчитан на доверенную локальную сеть.
· Моды не подписаны: проверяется только SHA-256 относительно того, что отдал сервер, — сервер сам может прислать что угодно.
· Сохранения не защищены от подделки: XOR с 8-битным ключом и sum()-чексуммой легко обходится.
· Читы отключают статистику — это осознанное ограничение.
· Максимум 14 игроков на сервере (по числу цветов).
